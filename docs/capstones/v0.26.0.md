# Ryftipe Web v0.26.0 — Bookmark portability capstone

## What changed

- Added browser-toolbar **Import** and **Export** actions beside the bookmarks shelf.
- Imports standard Netscape Bookmark HTML files, the interoperable format used by mainstream browsers.
- Exports the local bookmark collection to `ryftipe-bookmarks.html`, suitable for importing into another browser.
- Validates imported links: only absolute HTTP(S) URLs without embedded credentials are accepted. JavaScript, file, data, relative and other unsafe URLs are discarded.
- Deduplicates URLs, bounds collections to 200 entries, caps import files at 5 MB, and escapes HTML when exporting.
- Added automated tests for format compatibility, entity decoding, unsafe URLs, deduplication, escaping and collection limits.

## Notes

Bookmarks remain stored in this browser's local storage. This feature makes them portable; it does not introduce account sync or PostgreSQL.
